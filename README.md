# Task 3: REST API to Manage a List of Books

A simple REST API built using **Node.js** and **Express.js** to perform CRUD (Create, Read, Update, Delete) operations on a list of books with in-memory storage.

---

## 🚀 Objectives
- Build basic REST API endpoints using Express routing.
- Handle HTTP methods (`GET`, `POST`, `PUT`, `DELETE`).
- Parse JSON data and handle request/response objects.

---

## 🛠️ Tools & Technologies Used
- **Node.js** (JavaScript Runtime)
- **Express.js** (Web Framework for Node.js)
- **VS Code** (Code Editor)
- **Postman** (API Testing Tool)[cite: 1]
